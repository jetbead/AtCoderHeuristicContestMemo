# AtCoder Heuristic Contest 063

[TOC]

<img src="../imgs/ahc063.png" width=300>

## 問題概要

- https://atcoder.jp/contests/ahc063
- N\*N マスの盤面上に、色のついたエサがいくつかと色のついたヘビがいる
- ヘビは各ターンで4方向に移動でき、移動先にエサがある場合はそのエサを食べ、ヘビの胴体がある場合はそこを噛みちぎる
- エサを食べた場合は、ヘビの長さが1伸び、最後の色がその色になる
- 噛みちぎった場合は、噛みちぎった以降の胴体がその色のエサとして配置される
- 好みの色の列が与えられるので、できるだけ短い操作列でヘビの色列を好みの色列に近づけよ

## 時間

- 240 時間
